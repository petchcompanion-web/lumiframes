About LumiFrames

LumiFrames Studios is an anime advertisement platform. Studios manage multiple anime, each with videos, pictures, music and voice.

Version 2.0 · Vercel Blob storage · Global

Hierarchy: Studio → Anime → Media

Terms & Policies

  • Data stored in Vercel Blob (global storage).
  • Media shared across all users.
  • Do not upload material you do not own.
  • We may update these terms.
  • Use the platform responsibly.

Privacy Policy

Data is stored in Vercel Blob. We do not collect personal information beyond what you provide. Media and metadata are globally accessible.

Help & FAQ

How do I create an anime?
Go to Profile → Create New Anime → add title, cover, media → Publish.

Where is my data?
Stored in Vercel Blob (global storage).

Can I have multiple anime?
Yes. One studio can own many anime, each with its own media.
